# Finance Soul — как запустить с нуля (коротко)

Отдельно «запускать агента» не нужно. После установки Finance Soul сам подключается в каждой сессии Claude Code — дальше просто пишете обычными словами.

Подробная версия: [QUICKSTART.md](QUICKSTART.md).

## 1. Что нужно заранее

| Что | Проверка |
|---|---|
| Claude Code | `claude --version` |
| Python 3.9+ | `python3 --version` |
| openpyxl (для Excel) | `python3 -m pip install --user openpyxl` |

## 2. Установка (один раз)

Запустите `claude` и введите:

```
/plugin marketplace add aibatjardem/finance-soul
/plugin install finance-soul@finance-soul
/exit
```

**Проверка:** снова запустите `claude` и наберите `/finance-soul:` — должны появиться подсказки.

## 3. Первая модель

Создайте папку под свой бизнес:

```bash
mkdir moy-biznes && cd moy-biznes
claude
```

Внутри:

```
/finance-soul:setup
```

Отвечайте на вопросы: что продаёте, цена, затраты, сколько продаж, сколько денег есть, для кого модель. Не знаете цифру — пишите «не знаю»: Claude поставит оценку и пометит её как оценку.

## 4. Результат

В папке `.finsoul/models/main/out/`:

- `report.md` — отчёт: итог, сценарии, юнит-экономика, деньги
- `model.xlsx` — Excel с формулами. Ячейка «Сценарий» на листе «Входы»: `1` — базовый, `2` — оптимистичный, `3` — пессимистичный
- `checks.json` — проверки и предупреждения

## 5. Что писать дальше

| Пишете | Что будет |
|---|---|
| «что если цена на 10% ниже» | вариант модели рядом с основной и сравнение |
| «сколько денег нужно и на сколько месяцев хватит» | разбор денег и runway |
| «разбери как финдиректор» | агент CFO: красные флаги и улучшения с цифрами |
| «проверь модель» | агент-аудитор: ошибки, формулы, источники допущений |
| «напиши бизнес-план для инвестора» | бизнес-план на цифрах модели |

## Важно

Результат — черновик для проверки человеком, а не финансовая, налоговая или юридическая консультация. Налоги проверьте с бухгалтером.

Проблемы и идеи: <https://github.com/aibatjardem/finance-soul/issues>
