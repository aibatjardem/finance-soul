# Finance Soul — инструкция с нуля

Эта инструкция для тех, кто ставит Finance Soul впервые. За 10 минут у вас будет финансовая модель вашего бизнеса: отчёт и Excel с формулами.

## 1. Что нужно заранее

| Что | Зачем | Как проверить |
|---|---|---|
| **Claude Code** | в нём работает Finance Soul | `claude --version` в терминале |
| **Python 3.9 или новее** | на нём работает расчётное ядро | `python3 --version` |
| **openpyxl** (по желанию) | чтобы получить Excel | `python3 -c "import openpyxl"` — без ошибки |

**Нет Claude Code** — установите по официальной инструкции: <https://docs.claude.com/en/docs/claude-code/setup>.

**Нет Python:**
- macOS: обычно уже есть; если нет — <https://www.python.org/downloads/> или `brew install python`.
- Windows: <https://www.python.org/downloads/>, при установке отметьте «Add Python to PATH».
- Linux: `sudo apt install python3 python3-pip`.

**Excel-выгрузка:**
```bash
python3 -m pip install --user openpyxl
```
Без openpyxl модель всё равно считается, просто без файла `.xlsx`.

## 2. Установка плагина (один раз)

Запустите Claude Code (команда `claude` в терминале) и введите по очереди:

```
/plugin marketplace add aibatjardem/finance-soul
/plugin install finance-soul@finance-soul
```

Выйдите из Claude Code (`/exit`) и запустите снова — плагин подключается при старте.

**Проверка:** введите `/finance-soul:` — должны появиться подсказки (`setup`, `kernel-reference` и другие).

## 3. Первая модель

Создайте папку под бизнес или идею и откройте в ней Claude Code:

```bash
mkdir moy-biznes
cd moy-biznes
claude
```

Запустите настройку:

```
/finance-soul:setup
```

Claude задаст вопросы. Подготовьте ответы заранее — чем точнее, тем лучше модель:

- **Что продаёте и за что платят** — подписка, заказ, час услуги, штука товара.
- **Цена** за единицу, **без НДС**.
- **Переменные затраты** на единицу: материалы, эквайринг (~2%), комиссии, доставка, сдельная оплата.
- **Сколько продаж** в первые месяцы и откуда первые клиенты. Не пишите сразу плановый объём — первые месяцы почти всегда меньше.
- **Постоянные затраты в месяц**: зарплаты (с налогами), аренда, маркетинг, софт.
- **Разовые вложения**: оборудование, ремонт, техника.
- **Деньги**: свои взносы, инвестор, кредит (сумма, ставка, срок).
- **Ставка КПН** и откуда вы её взяли (статья кодекса, дата проверки).
- **Для кого модель**: инвестор, банк, госпрограмма или для себя.

Не знаете точную цифру — так и скажите. Claude поставит оценку и пометит её как оценку.

## 4. Что получится

Claude покажет итог в чате, а в папке появится:

```
moy-biznes/
└── .finsoul/
    ├── company.md          что за бизнес
    ├── metrics.md          какие показатели считаем и как
    ├── assumptions.md      все допущения: значение, источник, уверенность
    └── models/main/
        ├── inputs.json     входы модели
        └── out/
            ├── report.md   отчёт: итог, сценарии, юнит-экономика, деньги, P&L
            ├── model.xlsx  Excel с формулами
            └── checks.json проверки и предупреждения
```

**В Excel:** лист «Входы» — синие ячейки можно менять. Ячейка «Сценарий»: `1` — базовый, `2` — оптимистичный, `3` — пессимистичный; вся модель пересчитывается.

Пример готового результата: [отчёт](../examples/edtech/.finsoul/models/main/out/report.md), [Excel](../examples/edtech/.finsoul/models/main/out/model.xlsx).

## 5. Что можно просить дальше

Пишите обычными словами:

| Запрос | Что произойдёт |
|---|---|
| «что если цена на 10% ниже» | вариант модели рядом с основной, сравнение |
| «сколько денег нужно привлечь и к какому месяцу» | разбор денег и runway по трём сценариям |
| «проверь модель» | агент-аудитор: проверки, формулы, источники допущений |
| «разбери как финдиректор» | агент CFO: красные флаги и три улучшения с цифрами |
| «добавь второй продукт» / «поменяй аренду на 800 тысяч» | правка модели и пересчёт |
| «напиши бизнес-план для банка» | `.finsoul/business-plan.md` на цифрах модели |

## 6. Если что-то не так

| Проблема | Что сделать |
|---|---|
| Красная строка при старте `SessionStart:startup hook failed: Permission denied` | у вас версия 0.1.0 — обновитесь (ниже, «Обновить плагин»); в 0.1.1 исправлено |
| Нет команд `/finance-soul:...` | перезапустите Claude Code; проверьте `/plugin` → установленные плагины |
| «нужен Python 3.9 или новее» | установите Python (раздел 1) |
| «Нужен openpyxl» | `python3 -m pip install --user openpyxl` |
| Ошибка во входах (`revenue_streams[0].price: ...`) | Claude исправит сам; если нет — скажите «исправь ошибки во входах» |
| «модель не прошла проверки» | не используйте цифры, попросите «найди, почему не сходится баланс» |
| Команда `python3` не найдена (часто на Windows) | Python там часто вызывается как `python` — скажите Claude «запускай ядро через python» |

**Какая у меня версия:** `/plugin` → установленные плагины → finance-soul. Текущая — **0.1.1** (что изменилось — [CHANGELOG](../CHANGELOG.md)).

**Обновить плагин:**
```
/plugin marketplace update finance-soul
```
затем выйдите из Claude Code и запустите снова. Если старая ошибка осталась — переустановите:
```
/plugin uninstall finance-soul@finance-soul
/plugin install finance-soul@finance-soul
```
Папка `.finsoul/` в ваших проектах при обновлении и удалении плагина не трогается.

**Удалить:** `/plugin uninstall finance-soul@finance-soul`.

## Нашли проблему или хотите доработать под себя

- **Сообщить о проблеме:** <https://github.com/aibatjardem/finance-soul/issues> — что делали, что увидели (текст ошибки или скриншот), какая система.
- **Доработать самому:** склонируйте репозиторий и запустите Claude Code с локальной версией плагина:

  ```bash
  git clone https://github.com/aibatjardem/finance-soul.git
  cd finance-soul
  claude --plugin-dir plugins/finance-soul
  ```

  Меняйте профили, показатели, тексты, расчёты — что нужно вашему бизнесу. Что где лежит — в [CLAUDE.md](../CLAUDE.md). Для своей команды сделайте fork и ставьте из него: `/plugin marketplace add <ваш-логин>/finance-soul`.
- Полезное для всех — присылайте Pull Request.

## 7. Важно

- Результат — **черновик для проверки человеком**. Это не финансовая, налоговая или юридическая консультация. Налоги и структуру проверьте с бухгалтером.
- Версия 0.1: НДС не считается (цены без НДС), одна валюта, модель помесячная, нет оценки компании (DCF) и план-факта.
- Храните папку `.finsoul/` вместе с проектом (например, в git): допущения — часть проекта.

Нашли ошибку или есть идея — <https://github.com/aibatjardem/finance-soul/issues>.
