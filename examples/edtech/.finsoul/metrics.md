# Показатели проекта (EdTech)

| Показатель | Формула в этом проекте | Ориентир | Где считается |
|---|---|---|---|
| Активные ученики | ученико-месяцы за месяц | по плану набора | ядро: `units_0` |
| MRR | активные ученики × цена подписки | — | ядро: `revenue` |
| ARPU | выручка / активные ученики | ≈ цена подписки | из `revenue` и `units_0` |
| Отток в месяц | ушедшие / активные на начало месяца | ≤ 6–8% | вход `unit_economics.churn_monthly` |
| CAC | маркетинг за период / новые ученики | ≤ 1/3 LTV | вход `unit_economics.cac` |
| LTV | маржинальный доход на ученика в месяц / отток | — | ядро: юнит-экономика |
| LTV/CAC | LTV / CAC | ≥ 3 | ядро: юнит-экономика |
| Окупаемость CAC | CAC / маржинальный доход в месяц | ≤ 12 мес. | ядро: юнит-экономика |
| Маржинальность | (цена − переменные затраты) / цена | ≥ 70% для онлайна | ядро: юнит-экономика |
| Загрузка преподавателей | часы занятий / доступные часы | 70–85% | вне ядра v0.1 — считать отдельно и записать в `assumptions.md` |
