# Finance Soul

Душа финансиста для [Claude Code](https://claude.com/claude-code): финансовые модели (три связанные формы отчётности), юнит-экономика, деньги и runway, три сценария, чувствительность, бизнес-план. Ставится в любую папку и дальше работает с показателями именно вашего проекта.

**Главное правило: числа считает протестированное Python-ядро, а не языковая модель.** Claude готовит допущения и объясняет результат. Каждая цифра в отчёте прослеживается до входа и до строки в реестре допущений с источником. Excel выгружается с живыми формулами, и тесты проверяют, что его значения совпадают с ядром.

Устроен так же, как [AgentSoul](https://github.com/aibatjardem/agentsoul): душа загружается хуком при старте сессии, skills подгружаются по требованию, субагенты — изолированные исполнители.

> **Впервые? Коротко на одну страницу: [docs/START.md](docs/START.md). Пошаговая инструкция с нуля: [docs/QUICKSTART.md](docs/QUICKSTART.md)**

## Установка

В Claude Code:

```
/plugin marketplace add aibatjardem/finance-soul
/plugin install finance-soul@finance-soul
```

Нужен Python 3.9+, для Excel — `openpyxl` (`python3 -m pip install --user openpyxl`). Перезапустите Claude Code после установки.

**Обновление:** `/plugin marketplace update finance-soul` и перезапуск. Текущая версия — **0.1.1**, изменения — в [CHANGELOG.md](CHANGELOG.md). Если при старте видите `SessionStart:startup hook failed: Permission denied` — у вас 0.1.0, обновитесь.

**Нашли проблему?** Напишите в [Issues](https://github.com/aibatjardem/finance-soul/issues) — или склонируйте репозиторий и доработайте под себя (раздел «Доработать под себя» ниже, лицензия MIT).

## Быстрый старт

В папке проекта:

```
/finance-soul:setup
```

Опрос про бизнес → профиль (`blank`, `edtech`) → папка `.finsoul/` → первая модель → расчёт. Дальше просто просите: «построй финмодель», «что будет, если цена на 10% ниже», «сколько денег нужно привлечь», «напиши бизнес-план для банка».

## Что лежит в проекте

```
.finsoul/
├── company.md        бизнес, стадия, для кого модель, налоговый режим
├── metrics.md        какие показатели и как именно их считаем
├── assumptions.md    реестр допущений: значение, источник, уверенность, дата
├── local/*.md        правила проекта — сильнее всего остального
└── models/<имя>/
    ├── inputs.json   входы модели
    └── out/          report.md, checks.json, model.xlsx (генерирует ядро)
```

Плагин эти файлы не перезаписывает. Держите `.finsoul/` в git: допущения — часть проекта.

## Что внутри плагина

| Слой | Состав |
|---|---|
| Душа | красные линии финансиста, иерархия правил, карта команды; хук `SessionStart` сообщает состояние `.finsoul/` и путь к ядру |
| Skills | `setup`, `soul`, `kernel-reference`, `assumptions`, `three-statement-guide`, `unit-economics-guide`, `cash-runway-guide`, `business-plan-guide` |
| Субагенты | `model-builder` (собирает и считает модель), `model-auditor` (проверяет), `cfo-reviewer` (разбирает цифры глазами CFO) |
| Ядро | `kernel/finsoul`: три формы с проверкой баланса, перенос убытка по КПН, аннуитетные кредиты, оборотный капитал, юнит-экономика, cash/runway, NPV/IRR, сценарии, чувствительность, Excel с формулами |

Ядро можно запускать и без Claude:

```bash
python3 plugins/finance-soul/kernel/run.py build examples/edtech/.finsoul/models/main/inputs.json --out /tmp/edtech
```

## Пример

`examples/edtech/` — вымышленная онлайн-школа: 36 месяцев, подписка 25 000 KZT, взнос инвестора и кредит банка. Готовый [отчёт](examples/edtech/.finsoul/models/main/out/report.md) и [Excel](examples/edtech/.finsoul/models/main/out/model.xlsx). Ячейка «Сценарий» на листе «Входы» (1/2/3) пересчитывает всю модель.

## Ограничения v0.1

- НДС сквозной: входы указываются без НДС.
- КПН начисляется и платится в одном месяце, убытки переносятся вперёд; ставка задаётся во входах с источником, справочника налогов РК пока нет.
- Одна валюта модели, модель помесячная, без запасов.
- Нет DCF с терминальной стоимостью, план-факта и аудита чужих Excel-файлов.

## Дальше (v0.2)

DCF и оценка компании, план-факт с разложением отклонений, справочник налогов РК со сверкой по Налоговому кодексу 2026, аудит произвольных xlsx, 13-недельный прогноз денег, валюты, новые профили (SaaS, e-commerce, услуги, производство) и специалисты.

## Доработать под себя

Finance Soul открыт: склонируйте и меняйте что угодно — свои профили бизнеса, показатели, правила, отчёт, расчёты.

```bash
git clone https://github.com/aibatjardem/finance-soul.git
cd finance-soul
claude --plugin-dir plugins/finance-soul   # Claude Code с вашей локальной версией плагина
```

Своя версия для команды: сделайте fork на GitHub и ставьте плагин из него — `/plugin marketplace add <ваш-логин>/finance-soul`. Как устроен репозиторий и что где править — в [CLAUDE.md](CLAUDE.md). Улучшения, полезные всем, присылайте в Pull Request.

Проверка после правок:

```bash
python3 -m pip install --user -r requirements-dev.txt
python3 -m pytest
claude --plugin-dir plugins/finance-soul   # попробовать плагин вживую
```
